## 1. OFDM 信道估计与均衡

### 1.1 低 SNR 下与 SC-FDE 的 BER 差距

**现象：** 相同 SNR 下 OFDM BER 系统性高于 SC-FDE，QPSK 和 64QAM 均受影响，瀑布区差距尤为极端。

**QPSK + LDPC 14/15（AWGN）：**

| SNR | SC-FDE BER | OFDM BER | 差距 |
|-----|-----------|----------|------|
| 0 dB | 2.6e-2 | 4.2e-2 | 1.6× |
| **2 dB** | **1.1e-5** | **7.9e-3** | **725×** |
| 4 dB | 0 | 0 | 持平 |
| 10 dB | 0 | 0 | 持平 |

**64QAM + LDPC 14/15（AWGN）：**

| SNR | SC-FDE BER | OFDM BER | 差距 |
|-----|-----------|----------|------|
| 10 dB | 5.5e-2 | 7.0e-2 | 1.3× |
| 14 dB | 9.5e-4 | 1.6e-2 | **17×** |
| 18 dB | 0 | 0 | 持平 |

QPSK 在 2dB 的 725× 差距之所以极端，是因为 QPSK 的瀑布区极其陡峭（SC-FDE 从 2.6e-2@0dB 降至 1.1e-5@2dB，2dB 内改善 2400×）；OFDM 的 H 估计噪声导致有效 SNR 损失约 1dB，在瀑布区被放大为 100-1000× 的 BER 差距。两个模式在 4dB(QPSK)/18dB(64QAM) 同时归零，差距只存在于过渡区。
|-----|-----------|----------|------|
| 10 dB | 5.5e-2 | 7.0e-2 | 1.3× |
| 14 dB | 9.5e-4 | 1.6e-2 | **17×** |
| 18 dB | 0 | 0 | 持平 |

**根因：** 信道估计处理增益差异。

| | SC-FDE CES | OFDM Pilot-LS |
|---|---|---|
| 估计样本数 | 1024 (a512 + b512) | 3 个 OFDM 导频符号 |
| 处理增益 | ~30 dB | ~4.8 dB |
| H 估计等效 SNR @ 14dB | ~44 dB | ~19 dB |

OFDM 的 H 估计 SNR 比 SC-FDE 低约 25 dB。H 残差的尾部分布（outliers）对 64QAM 的紧密星座间距产生判决错误，EVM 仅差 16%（10.1% vs 11.8%），但 BER 差 47×。

### 1.2 CES 不可用于 OFDM

**尝试：** 用 SC-FDE 的 CES 互相关（a512+b512，1024 样本）替代 3 导频 LS 做 OFDM 信道估计。

**失败原因：** CES 互相关用**未滤波的**参考序列 a512/b512，但接收端 CES 字段已被脉冲成型滤波器 + 匹配滤波器卷积。互相关产生**有偏 CIR**。

| 估计方法 | EVM（AWGN, 24dB） | SFO 伪影 |
|----------|-------------------|----------|
| Pilot-LS（3 导频） | 5.96% | ~3e-7 rad/subcarrier |
| CES 互相关 | 9.14% | ~7e-5 rad/subcarrier |

SC-FDE 的 `FFT → ZF → IFFT` 闭环天然容忍此偏差（IFFT 平滑作用），OFDM 的纯频域 ZF 直接把偏差转为星座误差。

**结论：** OFDM 必须使用频域 Pilot-LS（无偏），不能复用 SC-FDE 的 CES。

### 1.3 导频密度受 LDPC 码率约束

当前 OFDM 帧结构：48 个 OFDM 符号，3 个导频，45 个数据符号。增加导频需满足 `N_DATA × code_rate = 整数`。LDPC 14/15 要求 N_DATA 为 15 的倍数。

| 导频数 | N_DATA | 14/15 整数？ |
|--------|--------|-------------|
| 3 | 45 | ✅ 45×14/15=42 |
| 6 | 42 | ❌ 42×14/15=39.2 |
| 18 | 30 | ✅ 30×14/15=28 |

增加导频密度需要同时调整 OFDM 符号数或码率，二者不可独立变化。

## 2. IQ 不平衡补偿

### 2.1 判决导向（DD）补偿在 OFDM 下无效

**测试条件：** AWGN 24dB, 64QAM, RX IQ 不平衡（增益 2dB, 相位 5°), 判决导向补偿。

**结果：**

| 模式 | 场景 | EVM | IRR | BER |
|------|------|-----|-----|-----|
| **SC-FDE** | 无 IQ | 3.17% | 74.7 dB | 0 |
| | IQ + 不补偿 | 15.81% | 20.1 dB | 3.5e-2 |
| | **IQ + 补偿** | **3.40%** | **80.5 dB** | **0** |
| **OFDM** | 无 IQ | 3.91% | 74.4 dB | 1.1e-3 |
| | IQ + 不补偿 | 15.03% | 62.7 dB | 3.7e-2 |
| | IQ + 补偿 | 14.74% | 58.3 dB | 3.9e-2 |

**SC-FDE：** DD 补偿几乎完全恢复——EVM 从 15.81% → 3.40%，IRR 从 20.1 → 80.5 dB，BER 归零。

**OFDM：** DD 补偿完全无效——EVM/IRR/BER 均无改善。

**根因：** 判决导向算法依赖 SC-FDE 的块结构（逐块硬判 → 重建发射符号 → LS 估计 IQ 参数）。OFDM 的符号分布在频域子载波上，星座格式和符号间关系与 SC-FDE 完全不同，算法无法直接迁移。

### 2.2 CES 基 IQ 补偿已移除

原 CES 基方法（利用前导码 CES 序列估计 I/Q 不平衡滤波器）在 short preamble 下矩阵不满秩（rank=6/11），无法使用。已从 THzReceiver 中移除，统一使用判决导向方法。

## 3. TDL 多径信道与系统兼容性

### 3.1 时延扩展严重失配

**系统参数：**
- 符号率：~30 GHz
- 符号周期：~0.033 ns
- CP 长度：32 符号 = **1.07 ns**

**TDL 模型（以 TDL-A, delay_spread=30ns 为例）：**

| 参数 | 值 |
|------|-----|
| RMS 时延扩展 | 30 ns |
| 最大归一化时延 | 9.6586 |
| 实际最大时延 | **290 ns** |
| 所需 CP | **8700 符号** |
| 当前 CP | 32 符号（差 270×） |

TDL-A~E 是为 3GPP 蜂窝系统（0.5–100 GHz 载频，15–60 kHz 子载波间隔）设计的。THz 系统（1 THz 载频，30 GHz 带宽）的符号周期比蜂窝系统小约 6 个数量级，TDL 的绝对时延在 THz 尺度下跨越数百个符号。

### 3.2 使用条件

TDL 需缩放到 THz 尺度：

```python
params.update(
    tdl_model="TDL-A",
    tdl_delay_spread_ns=0.3,   # 室内 THz 典型值 0.1–0.5 ns
    gi_length=128,             # 覆盖最大时延：9.66 × 0.3ns × 30GHz ≈ 87 符号
)
```

`tdl_delay_spread_ns=0.3ns` 时最大路径时延 ≈ 2.9 ns ≈ 87 符号。gi_length ≥ 128 可覆盖。

**代价：** CP 开销 = 128 / 480 = 26.7%。需权衡覆盖范围和帧效率。

### 3.3 全链路集成问题

| 问题 | 状态 |
|------|------|
| MultipathChannel.apply() 功能 | ✅ 正常（TDL-A~E 均生成正确的路径数、功率归一化、Jakes 时变） |
| 元数据传递 | ⚠️ AWGN/CFO 模块创建新 dict 时丢弃多径元数据（路径、功率等），不影响信号 |
| 轻多径全链路同步 | ✅ 单径/flat 瑞利正常（CoarseSync + FineSync 正确对齐） |
| TDL 全链路同步 | ❌ TDL 大时延扩展导致 CoarseSync 峰值偏移严重，需增强同步算法 |
| CP 覆盖 | ❌ 当前 CP=32 无法覆盖 ≥ 87 符号的最大时延 |

## 4. 建议与优先级

| 优先级 | 事项 | 说明 |
|--------|------|------|
| P0 | OFDM 低 SNR 差距 | 固有限制，仿真时 QPSK SNR 建议从 0dB 起；64QAM 差距在 18dB 消失 |
| P1 | TDL 参数缩放 | 设置 `tdl_delay_spread_ns=0.1~0.5`，同步增加 `gi_length` |
| P1 | 同步算法增强 | CoarseSync 需抗大多径时延的峰值检测策略 |
| P2 | OFDM IQ 补偿 | 判决导向方法对 OFDM 无效，需针对 OFDM 频域结构设计新算法 |
| P2 | 元数据传递 | 修改 AWGN.add_awgn() 保留输入 dict 的多径元数据字段 |
| P3 | OFDM 导频密度 | 切换码率或调整帧结构以容纳更多导频（约 18 个导频与 14/15 LDPC兼容） |
